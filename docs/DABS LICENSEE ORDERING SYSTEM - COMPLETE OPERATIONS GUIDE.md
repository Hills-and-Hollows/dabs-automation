## **STEP-BY-STEP OPERATING CHECKLIST**

### **□ 1\. ACCESSING THE SYSTEM**

* Navigate to licensee ordering login page  
* Enter username and password (same as current DABS credentials)  
* **If no account:** Contact DABS Help Desk (801) 977-6939 for setup

### **□ 2\. HOMEPAGE NAVIGATION**

* Review "New and Open Orders" section (top of page)  
* Scroll down to locate "Previous Orders" / invoice history  
* Verify system adapts properly to screen size/device

### **□ 3\. VIEWING & PRINTING INVOICES**

* Scroll to "Previous Orders" section on homepage  
* Select specific previous order to print  
* Click "Print Selected" button at top of list  
* **Use for:** Monthly reconciliation and record-keeping

### **□ 4A. CREATING NEW ORDER (FROM SCRATCH)**

* Locate "New and Open Orders" section at top of homepage  
* Select "New Order" option  
* Add items using search/add interface  
* Adjust quantities as needed

### **□ 4B. CREATING ORDER BY COPYING PREVIOUS ORDER ⭐ RECOMMENDED**

* Click "Copy Previous Order" button on homepage  
* Use selector field to find previous order to copy  
* Click green "Copy Order" button  
* **Result:** New draft order created with same items

### **□ 5\. EDITING DRAFT ORDER**

**Add Items:**

* Use item search interface to locate products  
* Add desired products to order

**Remove Items:**

* Delete line items for unwanted products  
* Verify removal before submitting

**Edit Items:**

* Adjust quantities directly on line items  
* Modify product details as needed

**Auto-Save Feature:**

* **IMPORTANT:** Order saves automatically while editing  
* If disconnected/timeout: Sign back in to continue  
* Draft order will be preserved

### **□ 6\. INVENTORY RESERVATION & ORDER SUBMISSION**

**Pre-Submission Check:**

* Review all items and quantities  
* Double-check newly added items  
* Verify total quantities match needs

**Submit Order:**

* **CRITICAL:** Inventory not reserved until submission  
* Click "Submit Order" button  
* **Result:** Inventory reserved, order processed

## **\--------------------------**

## **BEST PRACTICES & EFFICIENCY TIPS**

### **□ RECURRING ORDERS**

* **Always use "Copy Previous Order"** for regular purchases  
* Saves time and reduces entry errors  
* Maintains consistency in ordering patterns

### **□ INTERRUPTION RECOVERY**

* System auto-saves during order creation  
* Network timeout/page loss: Simply sign back in  
* Continue editing saved draft order

### **□ INVOICE MANAGEMENT**

* Print invoices immediately after order completion  
* Use "Previous Orders" section for historical records  
* **Integration:** Combine with monthly reconciliation template

## **\--------------------------**

## **TROUBLESHOOTING & SUPPORT**

### **COMMON ISSUES:**

* **Login Problems:** Verify username/password or call Help Desk  
* **Order Not Saving:** Check internet connection, refresh page  
* **Missing Previous Orders:** Contact Help Desk for account history

* **For:** Account setup, password reset, technical issues
