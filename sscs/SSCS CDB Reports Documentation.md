The best site for official technical documentation for **SSCS Computerized Daily Book (CDB) Reports** is the official SSCS site and their customer support/documentation portals. Here are the most authoritative resources:

- **Main product/features page:**  
  Provides overview and key links:  
  [SSCS Computerized Daily Book (CDB)](https://www.sscsinc.com/computerized-daily-book/)[1]

- **Official online CDB/CPB documentation:**  
  If you have access, SSCS hosts technical and user documentation here:  
  [Central Price Book/CDB Help](https://sscsta.sscsinc.com/Cpb.App/Help/index.html)[2]

- **User manuals:**  
  Extensive, downloadable documentation:
  - [Central Price Book User's Guide (PDF)](https://portal.sscsinc.com/wp-content/uploads/sites/3/documents/full_manuals/cpb40.pdf)[3]

- **Support options and documentation links:**
  - [SSCS Support Portal](https://www.sscsinc.com/support/)[4]
  - [Support Tools page](https://www.sscsinc.com/support-tools-2/)[5]
