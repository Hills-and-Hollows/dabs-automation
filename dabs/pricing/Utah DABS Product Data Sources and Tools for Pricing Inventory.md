tah DABS Product Data Sources and Tools
Utah’s Department of Alcoholic Beverage Services (DABS) provides several official, publicly accessible resources containing comprehensive product information. Below is a detailed list of key sources (with URLs or file names) and what each contains, including update frequency and available details:

Monthly Retail Price Books (PDF) – DABS publishes monthly price lists for all liquor products. Each fiscal month’s Retail Price List is available in three formats: Alphabetical by product name, Master Category, and Numeric by codeabs.utah.gov. For example, the September 2025 Retail Price Lists (Alpha, Category, Numeric) were posted with new prices effective September 1, 2025abs.utah.gov. These PDF books list every active product with its control state code (CSC), product name, size (mL), case pack (units per case), status code, category, and retail priceabs.utah.govabs.utah.gov. They also note any special pricing (SPA promotions) or new/old price changes. DABS updates these files each fiscal month (the site confirms they are generated on a monthly basisabs.utah.gov), and the PDFs themselves show the effective date and print timestamp for the latest updateabs.utah.gov. (File example: “Sept2025AlphaPriceList.pdf” on the DABS site, updated Aug 20, 2025 for Sep 2025 pricing).

Interactive Product List Spreadsheet (Excel) – The DABS website offers a downloadable Excel spreadsheet of the full product catalog for the current periodabs.utah.gov. For instance, the August 2025 Product List (FY26_P2.xlsx) contains an exportable list of all products in the system as of fiscal period 2 of 2026. Users can filter this spreadsheet by category or subcategory to view items by type (e.g. spirits, wine, beer)abs.utah.gov. The spreadsheet includes similar data as the price book (product description, size, CSC code, status, etc.), allowing users to slice the data by category (the site provides a key to category codes and divisions for reference). This Excel file is routinely updated with each price change cycle (each fiscal period) so that it reflects the latest active products and prices. (File name example: “August-2025-Product-List_FY26_P2.xlsx” on abs.utah.gov). Note: “CSC” is the unique product identification code used by DABSabs.utah.gov. The status codes in the list indicate distribution type (e.g. “1” for general item, “D” discontinued, “S” for special-order only items, etc.)abs.utah.gov.

DABS Online Product Locator (Search Portal) – DABS provides a web-based Product Lookup tool (on the webapps2.abc.utah.gov domain) that allows interactive searching of the entire product databasewebapps2.abc.utah.gov. This Product Locator portal lets users search by product name or filter by category, subcategory, price range, or status. The tool displays live data including the product’s Name, SKU (code), subcategory, status (e.g. general, limited, special order), and current retail price, as well as real-time inventory levels (warehouse quantity, store quantity, and on-order quantity)webapps2.abc.utah.gov. All major categories are covered (spirits, wines by type, beers, flavored malt beverages, etc., including a category for “Beer – Special Orders”)webapps2.abc.utah.gov. This online database is actively maintained in real time by DABS – it reflects current in-stock items and can be used to check product availability across state stores. (Accessible via the “Shop Now” link on the DABS site, it runs the DABS Product Locator web app in productionwebapps2.abc.utah.gov.) Note: There are no individual static product pages; instead, this lookup tool serves that purpose by returning product details on query. You can refine results by status (for example, show only “S” special-order items) or show only new items/SPAs, but UPC and ABV are not displayed in this interface (only the attributes mentioned above).

Special Order Products and Portal – Special-order items (products not regularly stocked but available on request) are included in the above price lists and database, flagged by status “S” and grouped under special-order categories (e.g. category codes beginning with Y for special-order spirits, wine, beer, etc.)abs.utah.govabs.utah.gov. DABS maintains a Special Order Program for customers seeking products the state doesn’t currently carry in storeswebapps2.abc.utah.gov. There is an online Special Orders portal where consumers or licensees can submit requests – this requires creating an account and logging in (separate login options for retail customers vs. restaurants/clubs are provided)webapps2.abc.utah.gov. Through this system, one can input product details (name, size, vintage, distributor info, etc.) to order items not in the general catalog. While this special-order request site doesn’t offer a browsable list of all unlisted items (since it’s a request form), it is an official tool for accessing a wider selection through authorized distributorswebapps2.abc.utah.gov. All “S” status products that have been approved for special order have entries in the main product lists (often with pricing and a CSC code), effectively serving as a special order catalog embedded in the overall product data. The special-order web portal is actively maintained (latest platform version noted as 2025) and is the current method to initiate orders for those items not in regular stock. (See DABS “Special Orders” page for guidelines and account loginwebapps2.abc.utah.govwebapps2.abc.utah.gov.)

Approved Canned Cocktails (RTDs) List – DABS publishes a specific list of pre-approved canned cocktails (ready-to-drink cocktails) that can be sold by on-premise licensees (bars, restaurants) under recent law changes. This resource is provided via a Google Looker Studio reportabs.utah.gov. It includes details on each approved RTD cocktail product, likely including the brand, product name, size, and alcohol by volume (ABV) (since only certain low-ABV canned cocktails are allowed for on-premise sale). The Looker Studio interface allows users to view and export the list of approved canned cocktail SKUs. This list is updated by DABS as new RTD products are approved for on-premise sale. (Link available on the DABS site’s Product Lists page – “Approved Canned Cocktails for On-Premise Retail Sales”abs.utah.gov.) This is a more specialized product data source focusing on a subset of products with their ABV and other info relevant to on-premise usage.

Off-Premise Approved Products List (Grocery Store Items) – (For completeness) DABS also maintains a public list of beer and related products approved for sale in grocery and convenience stores (i.e. off-premise retail, typically beer ≤5% ABV). While these lower-ABV products are not sold in state liquor stores, the DABS oversees their approval. The Approved Off-Premise Products list is available on the DABS site as an interactive table, which can be exported as CSV/Excelabs.utah.gov. It shows all brands and products that have received approval for sale outside the state-run system, and it is updated regularly with new approvalsabs.utah.gov. This list typically includes product names, producers, and possibly details like container size and ABV (since eligibility is ABV-dependent). (Accessible via the “Off-Premise Retail Products” page on the DABS websiteabs.utah.gov.)

Data fields and Updates: Across these sources, you will find product codes (CSC SKU), product names/descriptions, sizes (volume), pack configuration, pricing, and categorization. Case pack information is explicitly provided (e.g. 12 bottles per case) in both the Excel and PDF price listsabs.utah.gov. However, UPC codes and detailed ABV percentages are generally not included in the standard price books or product locator outputs. (Any needed UPC or barcode data would have to be obtained from suppliers or package labels, as DABS does not publish UPCs in its price list files.) ABV appears only in context-specific resources like the canned cocktail and off-premise lists, not in the regular retail catalog. All the above sources are official and actively maintained by Utah DABS. The monthly price lists are kept current to the latest fiscal month’s prices (for example, new price sheets are issued effective each month with the last update timestamp noted on the documentabs.utah.gov), and the online tools (product search and special-order system) reflect up-to-date information (current inventory statuses or the latest program guidelines). Here’s a structured summary of Utah DABS Product Data Sources and Tools, highlighting how and where to find case pack, price, and product details for any Utah-controlled product (including POS/inventory onboarding):

1. Monthly Retail Price Books (PDF)

Description: Official monthly PDFs listing every product sold by DABS.

Formats: Alphabetical (by product name), Master Category, and Numeric (by product code/CSC).

Key Fields: Product Code/CSC, Product Name/Size, Case Pack (units/case), Status (General/Special/Discontinued), Retail Price, Category.

Updates: Every fiscal month — new prices effective the 1st of each month.

Links/Examples:

All lists page: abs.utah.gov/vendors/monthly-price-books/

September 2025 Alpha: abs.utah.gov/wp-content/uploads/Sept2025AlphaPriceList.pdf

Also available as: ...CategoryPriceList.pdf, ...NumericPriceList.pdf, ...AlphaPriceList.pdf

Use Case: This is the gold standard for on-premise/off-premise case size & price per unit.

2. Interactive Product List Spreadsheet (Excel)

Description: Downloadable spreadsheet with the entire DABS active product catalog.

Key Fields: Product description, SKU/CSC, product size, pack configuration, category, status, retail price.

Filtering: By type, category, or subcategory; provides a key for code meaning (“1” = general, “D” = discontinued, “S” = special order).

Updates: Each new price period (monthly or by fiscal cycle).

Find At: abs.utah.gov/shop-products/interactive-product-list/

Excel file example: “August-2025-Product-List_FY26_P2.xlsx”

3. DABS Online Product Locator (Web Portal)

Description: Searchable web tool for the live product database, showing name, code, category, size, status, and retail price.

Key Features: Shows in-stock/warehouse quantities, price, and live status; robust filter options (by category, status, etc.).

Limitations: Does not show UPCs or detailed ABV, but has virtually all other product details.

Access: webapps2.abc.utah.gov/ProdApps/ProductLocatorCore

4. Special Order Products and Portal

Description: Flagged in main catalog’s price list/Excel (status “S” or category code with “Y-”).

Special Orders Portal: Allows requests for items not in regular stock (account/login required).

Find At: webapps2.abc.utah.gov/ProdApps/SpecialOrdersCore

Note: Special order SKUs have entries in price books and the Excel, so you can track pricing/case size even for special-order items.

5. Approved Canned Cocktails (RTDs) List

Description: Looker Studio report with only pre-approved canned cocktails for on-premise sale (includes ABV where relevant).

Updates: When new RTD can cocktails are approved for on-premise sales.

Find At: abs.utah.gov/shop-products/interactive-product-list/#:~:text=Approved%20Canned%20Cocktails%20for%20On,Retail%20Sales

6. Off-Premise Approved Products List (Grocery/Convenience Store)

Description: List (interactive/exportable) of beer (≤5% ABV) and similar items allowed for sale outside state stores.

Find At: abs.utah.gov/licenses-permits/off-premise-products

Key Data Fields & Usage Notes

Case Pack and Size: Explicit for every product in retail PDFs and Excel lists — use these for accurate price-per-bottle/can conversions and for POS import.

Status: “1” (general), “S” (special order), “D” (discontinued), etc. — status code meaning is documented in Excel product list.

Price Validity: Always use the current month’s price book or spreadsheet for the most accurate prices.

UPC/Barcode: Not published in DABS data; must be obtained from suppliers, packaging, or separate industry product databases.

ABV: Not listed in default DABS lists except for select RTD/grocery/off-prem lists; search those resources for ABV info as needed.

Update Frequency: All resources are updated monthly or per fiscal cycle, with print timestamps and versioning in each file and on each web tool.

 For POS and onboarding, always ingest the latest Alpha or Numeric PDF or the Excel product list for case/bottle/can breakdowns, price, and SKU.
